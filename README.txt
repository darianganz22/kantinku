KANTINKU CUSTOMER - LANJUTAN 2

Halaman:
- index.html             : katalog utama
- menu-detail.html?id=1  : detail menu
- checkout.html          : checkout
- payment.html           : metode pembayaran
- order-status.html      : status pesanan
- history.html           : riwayat pesanan
- profile.html           : profil siswa
- help.html              : FAQ + customer service

Data antar halaman menggunakan localStorage.
Pembayaran masih simulasi frontend dan dapat diintegrasikan ke backend/payment gateway.

FITUR DRAWER KERANJANG:
- Tambah item langsung dari kartu menu
- Drawer bisa dibuka/tutup
- Tombol + / - per item
- Hapus item
- Subtotal otomatis
- Promo HEMAT3 (Rp 3.000, minimum Rp 20.000)
- Total setelah diskon
- Checkout membawa data keranjang + promo ke checkout.html
